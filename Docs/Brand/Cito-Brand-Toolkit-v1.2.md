## Type
- Headings: Space Grotesk, then Inter/system fallback
- Body/UI: Inter, then system/Arial fallback

## Themes
- **Cito**: default full-colour product theme.
- **Monochrome**: neutral product chrome using the approved black mark.
- Light/dark/system appearance remains a separate user choice.
- Semantic transaction/risk states retain explicit text and may retain semantic colours.

## Layout direction
The implementation may draw from the supplied reference dashboard for:
- compact left navigation;
- clear top-bar controls;
- balanced metric cards;
- denser but readable analytical panels;
- restrained dividers and shadows;
- useful empty states that do not consume the whole viewport.

Do not reproduce the reference dashboard's decorative header image.

## Usage rules
Keep proportions intact, provide clear space, use clean backgrounds, and never skew, rotate or recreate the supplied mark. Use the mark at sizes where its circuitry remains legible. Keep Cito as the platform identity and CPay as the payments service/channel where appropriate.
